# Tài liệu EduDSS

| Thư mục | Nội dung |
|---|---|
| `ai/` | Kiến trúc tầng AI: định tuyến 3 tầng (`AI_ROUTING_MATRIX.md`), điều phối agent, ngân sách token, nhật ký quyết định, khả năng chịu lỗi, kiểm toán cache. |
| `architecture/` | Kiến trúc hiện hành (`ARCHITECTURE.md`, bản nháp), lộ trình và phác thảo kiến trúc quy mô lớn. |
| `database/` | Schema PostgreSQL: danh sách bảng, sơ đồ quan hệ, RLS, chuỗi migration (`SCHEMA.md`, bản nháp). |
| `operations/` | Vận hành: sao lưu/khôi phục, quy trình phát hành, khôi phục Streamlit, xử lý dữ liệu cá nhân trong lịch sử git. |
| `planning/` | Kế hoạch, danh sách việc cần làm (TODO) và ghi chép quá trình phát triển (lịch sử, không phải đặc tả hiện hành). |
| `requirements/` | Yêu cầu sản phẩm (bản nháp): `PRD.md`, phạm vi bản đầu `MVP_SCOPE.md`, tiêu chí nghiệm thu `ACCEPTANCE_CRITERIA.md`. |
| `ux/` | Bản đồ màn hình theo vai trò (`SCREEN_MAP.md`, bản nháp). |
| `CONVENTIONS.md` | Quy tắc đặt tên, lint/format, nhánh và commit. |

Báo cáo kiểm thử/nghiệm thu nằm ở `../reports/`. Các báo cáo đó là bản chụp tại thời điểm viết;
một số đường dẫn cũ trong đó đã được cập nhật sang vị trí mới trong `docs/`.
