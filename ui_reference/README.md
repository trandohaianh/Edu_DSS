# EduDSS UI Reference Kit
Static visual specification only.

Structure:
- login.html + login.css
- styles.css shared by role screens
- lecturer/: dashboard, students/data, risk, training, prediction, clustering, AI advisor, reports, history
- student/: dashboard, analytics, prediction, learning plan, AI assistant, resources, history
- admin/: dashboard, data, users, model management, registry, knowledge base, reports, AI config, settings

Use these as visual source-of-truth when rebuilding Streamlit. Keep authentication, RBAC, ML, RAG, LLM and Model Registry logic unchanged.
